# Assets Klasörü

Bu klasör HDR görüntü dosyalarını içerir (opsiyonel).

HDR dosyası bulunamazsa, uygulama otomatik olarak düz renk arkaplan kullanır.

## HDR Dosyası Eklemek İçin

1. `plains_sunset_4k.hdr` dosyasını buraya kopyalayın
2. Veya kendi HDR dosyanızı kullanın (wing_api_client.js içinde yolu güncelleyin)

HDR dosyaları yüksek kaliteli çevre aydınlatması sağlar ancak zorunlu değildir.
